# VoidSINT — منصة OSINT للتحقيق الاستخباراتي

**مستوحاة من مشروع [Flowsint](https://github.com/reconurge/flowsint) العالمي**

> منصة استخبارات مفتوحة المصدر (OSINT) احترافية — من نقطة انطلاق واحدة، ابنِ خريطة تحقيقية متكاملة.

---

## ⚡ نظرة عامة

VoidSINT هي منصة تحقيق OSINT مبنية بـ React 19 + TypeScript، مستوحاة من فلسفة **Flowsint** في التحقيق القائم على الرسم البياني. تتيح للمحللين والباحثين الأمنيين بناء صورة استخباراتية متكاملة عن أي هدف.

---

## 🔍 محركات التحقيق (8 محركات)

| الكود | المحرك | الوصف |
|-------|--------|-------|
| OSINT-01 | ماسح أسماء المستخدمين | كشف الحضور على **34 منصة** تواصل اجتماعي |
| OSINT-02 | محقق البريد الإلكتروني | كشف التسريبات والهوية وتحليل النطاق |
| OSINT-03 | استخبارات عناوين IP | موقع جغرافي · ASN · السمعة الأمنية |
| OSINT-04 | محلل النطاقات | WHOIS · DNS · SSL · أرشيف الويب |
| OSINT-05 | استعلام أرقام الهاتف | كشف الدولة والمشغل والهوية المرتبطة |
| OSINT-06 | محلل المحافظ الرقمية | BTC · ETH · LTC · XRP · تتبع المعاملات |
| OSINT-07 | بحث الهوية الشخصية | تجميع المعلومات من الاسم عبر 8+ قنوات |
| OSINT-08 | مستخرج مؤشرات الاختراق | استخراج IPs · نطاقات · هاشات · CVEs |

## 🗺️ خريطة الروابط التحقيقية

- رسم بياني تفاعلي SVG لشبكة العلاقات بين الكيانات
- إضافة كيانات من نتائج التحقيق بنقرة واحدة
- ربط الكيانات بتسميات العلاقات
- حفظ تلقائي في المتصفح (localStorage)
- سحب وإفلات تفاعلي

---

## 🛠️ المكدس التقني

- **React 19** + **TypeScript**
- **TanStack Router** — توجيه ملف-مبني
- **Tailwind CSS v4** + **shadcn/ui**
- **Vite 7** — أداة البناء
- **IBM Plex Sans Arabic** — خط عربي احترافي
